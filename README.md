# Проект Яндекс Лицей «MP3-плеер»

Автор: Смирнов Егор

## Идея проекта

Моя программа — настольный MP3-плеер на PyQt6. Он не просто проигрывает файлы: он хранит библиотеку музыки, позволяет собирать плейлисты и ведёт дневник прослушиваний, по которому строится статистика: что и сколько я слушал сегодня, за 7 дней и за всё время. Дневник — главная идея проекта: в него попадает только то, что действительно прослушано (не меньше 30 секунд), а перемотка и пауза время не накручивают.

## Как пользоваться

После запуска открывается главное окно: обложка, название и исполнитель, очередь воспроизведения, кнопки управления, ползунки перемотки и громкости. Музыку добавляют через меню «Файл» (отдельные файлы или целую папку). Трек запускается кнопкой Play или двойным щелчком по очереди. Кнопки позволяют перейти к предыдущему и следующему треку, включить случайный порядок и повтор (выключен, один трек, весь список). Громкость и последний трек запоминаются между запусками. Через меню «Сервис» включается таймер сна: через заданное число минут музыка остановится сама.

## Окна программы

- **Главное окно** — воспроизведение и очередь.
- **«Библиотека»** — все треки, поиск по названию и исполнителю, сортировка, изменение названия и исполнителя, удаление, добавление треков в плейлист.
- **«Плейлисты»** — создание, переименование и удаление плейлистов, перестановка и удаление треков, экспорт плейлиста в CSV и импорт списка путей из TXT.
- **«Статистика»** — три вкладки (сегодня, 7 дней, всё время): топ-10 треков, общее время прослушивания и доля самого популярного трека.

Окна открываются из меню «Окна» и общаются с главным окном через сигналы PyQt.

## Технологии

PyQt6 (QtWidgets, формы Qt Designer в файлах .ui), QtMultimedia (QMediaPlayer и QAudioOutput) для звука, sqlite3 для базы данных, mutagen для чтения тегов и обложек MP3, модуль csv и текстовые файлы для обмена данными, QSettings для хранения настроек. Использованы виджеты QSlider, QTabWidget, QProgressBar, QTableWidget, QListWidget, QComboBox, QLineEdit и стандартные диалоги QFileDialog, QInputDialog, QMessageBox. Картинки: иконки кнопок и заглушка обложки лежат в папке assets, а настоящая обложка берётся из тегов файла.

## База данных

Четыре таблицы SQLite (файл `data/player.db` создаётся при первом запуске):

- `tracks` — библиотека (путь, название, исполнитель, альбом, длительность);
- `playlists` — плейлисты;
- `playlist_tracks` — состав и порядок плейлиста;
- `play_history` — дневник прослушиваний (трек, время, сколько секунд прослушано).

Весь SQL находится в одном классе `Database`, остальной код только вызывает его методы. Программа читает данные (поиск, статистика), записывает их (новые треки, плейлисты, дневник) и изменяет (правка треков, переименование плейлистов, перестановка треков).

## Структура проекта

    main.py              точка входа
    paths.py             пути к ресурсам и данным (работают и в exe)
    windows/             окна: главное, библиотека, плейлисты, статистика
    ui/                  формы Qt Designer (.ui) для каждого окна
    core/                логика без интерфейса: плеер, очередь, теги, таймер сна, настройки
    data/                работа с данными: database.py (весь SQL), exchange.py (CSV и TXT)
    assets/              иконки кнопок и картинка-заглушка для обложки
    tests/               автоматические тесты

## Запуск

Нужен Python 3.9 или новее.

    pip install -r requirements.txt
    python main.py

В PyCharm: откройте папку проекта, создайте виртуальное окружение (Settings → Project → Python Interpreter → Add Interpreter → Virtualenv → New), установите зависимости из `requirements.txt` и запустите `main.py`.

Тесты логики:

    python -m unittest discover -s tests -t .

Сборка exe (Windows): запустите `build_exe.bat`, готовый файл появится в `dist\MP3Player.exe`.

## Недостатки и доработки

Поддерживаются только MP3. Ползунок перемотки работает при перетаскивании, но не при щелчке по полосе. Пути к файлам хранятся полностью, поэтому после переноса музыки в другую папку треки нужно добавить заново. Изменение названия и исполнителя меняет только запись в базе, а не теги самого файла. В будущем всё это можно доработать.
